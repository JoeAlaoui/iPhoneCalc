## Features

- iPhone-inspired design and layout
- Glassmorphism effect for modern UI
- Responsive: works on mobile and desktop
- Standard calculator functions (AC, ±, %, ÷, ×, −, +, =, ⌫)
- Toggle sign and backspace functions
- Built using semantic and accessible HTML
- Clean, readable code

## Getting Started

To run this project locally:

1. Clone the repository:
   ```sh
   git clone https://github.com/JoeAlaoui/iPhoneCalc.git
   ```
2. Open `index.html` in your browser.

No build tools or dependencies required!

---

## Usage

- Click the number and operator buttons to enter calculations.
- Use **AC** to clear all, **±** to toggle sign, **%** for percentage, and **⌫** to delete the last character.
- Responsive design adapts to your device size.

---

## Design Highlights

- **Glassmorphism:** Frosted glass effect for info sections, inspired by iOS design.
- **Button Layout:** Circles for all buttons, matching iPhone calculator ergonomics.
- **Color Coding:** Lighter gray for function buttons, orange for operators, dark for numbers.
- **Accessibility:** Large display, clear button icons, keyboard and screen reader friendly (improve further as needed).
